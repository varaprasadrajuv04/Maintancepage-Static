📋 Maintenance Page - Static Version Setup

✅ Status: Your static maintenance page is ready for Azure App Service!

🖼️ Adding Your Maintenance Image

Step 1: Copy Your Image

The app expects an image file at:

images/Maintenance-Page-GenAIQEP.png

Copy your original image file to the images/ folder:

  • From: Maintancepage/public/images/Maintenance-Page-GenAIQEP.png
  • To: Maintancepage-Static/images/Maintenance-Page-GenAIQEP.png

Step 2: Supported Image Formats

You can use any of these image formats:

  • PNG (.png)
  • JPEG/JPG (.jpg, .jpeg)
  • GIF (.gif)
  • WebP (.webp) - Best compression
  • SVG (.svg)

Step 3: Test Locally

Before deploying to Azure, test locally:

Using Python:

python -m http.server 8000

Using Node.js (http-server):

npx http-server

Then open: http://localhost:8000

🚀 Deployment Options

Choose one of these methods:
  • Azure Portal: Upload files directly via browser
  • Azure CLI: Deploy via command line
  • Visual Studio: One-click publish
  • VS Code: Using Azure extension
  • Git: Deploy via git push

See DEPLOYMENT_GUIDE.md for detailed instructions for each method.
